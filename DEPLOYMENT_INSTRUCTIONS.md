## 📦 Option 1: Standalone Windows Executable (.exe)
**Goal:** Create a single `.exe` file that runs on any Windows 10/11 machine without needing Python installed.

### 🛠️ Technical Details for the Build
*   **Tool:** `PyInstaller` (version 6.0+)
*   **Entry Point:** `3_run_app.py`
*   **Hidden Imports:** `ultralytics`, `customtkinter`, `PIL`, `cv2`, `numpy`, `torch`.
*   **Critical Data Files:**
    - `yolov8n-face.pt` (Face Detector)
    - `models/emotion_classifier/best.pt` (Emotion Model)
    - `models/emotion_classifier/best.onnx` (Optimized Model)
*   **UI Assets:** `customtkinter` requires its internal theme files to be included.

## ⚠️ Common Deployment Pitfalls (Read Carefully)
1.  **Missing DLLs:** On Windows, PyInstaller sometimes misses `opencv` DLLs. If the app crashes instantly, you may need to install `pip install opencv-python` instead of `opencv-contrib-python`.
2.  **Path Errors:** This is the #1 reason for failure. When packaged into an `.exe`, `os.getcwd()` changes. Always use `Path(__file__).parent` logic.
3.  **Hugging Face "Headless" Error:** For web deployment, use `opencv-python-headless`. The standard `opencv-python` will try to open a GUI window on the server and crash.
4.  **Model Size:** YOLO models are large. If the `.exe` is over 500MB, ask Claude to use "Dynamic Linking" to reduce size.
